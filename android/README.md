# ARIA Android client

Simple Kotlin / Jetpack Compose chat client for the ARIA API (no server changes needed).

## Build and install
1. Open the `android/` folder in Android Studio (Ladybug or newer, JDK 17). Gradle sync generates
   whatever is missing (the Gradle wrapper jar is not committed; run `gradle wrapper` if you build from the CLI).
2. Run on a device, or `./gradlew assembleDebug` and install `app/build/outputs/apk/debug/app-debug.apk`.

## Server URL
Default: `http://100.91.177.31:5000` (the Tailscale address of the API host). Change it in the app via
menu → **Server URL**; the value is saved on the device. "Test connection" calls `GET /health`.

## Notes
- The phone needs Tailscale running. The API is plain HTTP; cleartext is allowed through
  `res/xml/network_security_config.xml` because traffic is already inside Tailscale's WireGuard tunnel.
- The API has no auth; Tailscale is the access boundary.
- Attach button: `.xlsx .xls .csv .json .parquet .tsv` go to `/datafiles/upload` (code executor);
  `.pdf .txt .md` go to `/sources/upload` (RAG). Files over 15 MB are rejected.
- Each chat has its own `thread_id`; "New chat" starts a fresh one (new memory, new files).
- Files generated by the code executor appear as links under the answer and open in the browser.
